OSSUARY

roguelike ASCII — dungeons de Rogue/NetHack · mundo de Fallout/Qud · visual Fósforo & Osso
Alpha v0.1 · 73/73 testes + protocolo desktop PASS · build Windows 01/10/2026
App desktop Tauri 2 + Rust · terminal Canvas bitmap · motor C#/.NET 10

A Visão

  • Dungeons: Rogue + NetHack — procedural, escadas, armadilhas, fome, morte permanente.
  • Mundo: Fallout 1/2 + Caves of Qud — overworld com regiões, cidades-hub, viagem com custo de tempo, história emergente.
  • Visual: Fósforo & Osso — terminal anos 80, fundo índigo, fonte unscii 8×16 sem suavização, CRT ajustável.

Feito (verificado)

  • ✔ Simulação: 5 branches (~54 níveis, 6 estilos), 25+ monstros, combate, FOV, fome, status, RPG (raças, classes, magia, deuses)
  • ✔ Overworld 96×60 (dia/noite, estradas, encontros) + cidades com lojas compráveis e economia
  • ✔ Objetivo final: Amuleto de Yendor no fundo + extração = vitória
  • ✔ HUD, 10+ painéis, mira, viagem, minimapa, título, opções, 4 temas
  • ✔ Suite headless 73/73 + protocolo desktop + 8 testes frontend/IPC + 2 Rust
  • ✔ AGENTS.md + docs/ (visão, arquitetura, sistemas, rpg, balance, visual, desktop)

Fazendo agora
